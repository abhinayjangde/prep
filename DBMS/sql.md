SQL is a `declarative` programming language used for managing and manipulating relational databases. It allows users to perform various operations such as querying data, inserting records, updating existing data, and deleting records from a database.

```sql
SELECT * FROM users WHERE age > 20;
```

In GATE exam they ask standard ANSI SQL commands. Not PostgreSQL, MySQL, or Oracle specific commands. So, you should focus on standard SQL commands.
